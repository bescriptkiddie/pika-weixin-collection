> 不满意你的 Claude Code 宠物？
一个命令行，让你直接抽到最稀有的宠物！


哈喽，大家好，我是刘小排。

ClaudeCode已经有电子宠物功能了。在ClaudeCode里输入/buddy即可领取自己的电子宠物。

一开始，我领取到的电子宠物是——一只普普通通的鸭子。调试能力55，智商15，吐槽能力9……简而言之就是，弱爆了。

ClaudeCode的/buddy电子宠物功能共有18种宠物，分5个稀有度等级：

ClaudeCode一共有18种电子宠物，分别是：鸭子(Duck)、鹅(Goose)、猫(Cat)、兔子(Rabbit)、猫头鹰(Owl)、企鹅(Penguin)、乌龟(Turtle)、蜗牛(Snail)、龙(Dragon)、章鱼(Octopus)、美西螈(Axolotl)、幽灵(Ghost)、机器人(Robot)、斑点(Blob)、仙人掌(Cactus)、蘑菇(Mushroom)、胖宠(Chonk)、水豚(Capybara)。

另外，每只宠物还有独立的1%概率成为"闪亮（Shiny）"变体，带虹彩动画效果。

一只普普通通的鸭子？也太无聊了吧！！

我想要拥有「传奇」稀有度的宠物啊！！

说干就干！

我让ClaudeCode阅读了昨天刚刚泄露的ClaudeCode的源代码，找到了里面生成电子宠物的机制。

然后根据代码，制作了一个小工具，一键刷宠物，想要什么要什么！

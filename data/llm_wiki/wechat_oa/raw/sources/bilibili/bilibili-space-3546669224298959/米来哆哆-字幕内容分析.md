# 米来哆哆 B 站字幕内容分析

> 基于 48 条视频的 B 站 `ai-zh` 字幕整理。以下是内容方法论分析，不构成投资建议。

## 数据概况

- 视频数量：48
- 时间跨度：2025-03-17 至 2026-05-19
- 字幕段落：25,348 段
- 字幕来源：B 站登录态可见 AI 中文字幕（`ai-zh.srt`）
- 高频主题词：题材、涨停、炸板、分时、板块、科技、主力、回调、指数、个股、消息、放量、低吸、出货、业绩、洗盘、修复

## 内容定位

米来哆哆的内容不是纯宏观解读，也不是单纯股票推荐，而是偏短线交易训练的“盘面识别 + 题材节奏 + 个股执行”体系。

他的核心受众更像是已经开始看盘、但还无法把指数、题材、个股、分时、成交量串起来的新手或进阶散户。内容经常围绕一个具体交易困惑展开：能不能追、要不要卖、是洗盘还是出货、题材是否还能继续、强势股该怎么上车、炸板票还能不能做。

## 方法论主线

1. 先看市场状态，再看题材强弱。

   他很少孤立讨论个股，通常先判断指数是否有系统性风险，再看板块处于轮动、修复、兑现、退潮还是继续加强。这里的关键词是“指数不决定一切，但会决定仓位和容错”。

2. 题材里面重个股，只看核心只看强。

   字幕中“题材”“板块”“个股”“核心”的出现频率很高。他的观点不是平均看一个板块，而是识别最能代表资金态度的核心股、容量股、连板股、趋势股。弱跟风不值得浪费注意力。

3. 用量价和分时识别主力行为。

   “放量”“缩量”“分时”“盘口”“洗盘”“出货”构成了他的技术语言。判断逻辑通常不是单一指标，而是把位置、成交量、分时承接、拉升方式、回落方式、尾盘行为放在一起看。

4. 低吸优先，追高要有更强确认。

   “低吸”明显高频，而“追高”出现少得多。他更强调在分歧、回调、强势题材核心股的可控位置参与，而不是情绪一致后冲进去。涨停炸板相关内容很多，但核心不是鼓励乱追炸板，而是讲清楚炸板后的承接、次日预期和失败条件。

5. 卖点和仓位是新手最需要补的短板。

   他反复讲“少亏即赚”“控制仓位”“如何卖票”“分时卖点”。这说明他的交易教育不只讲买点，也在努力把用户从“只想买到牛股”拉回到“先能活下来、能处理波动”的框架。

## 可拆解的技能模块

### 1. 市场复盘 Skill

输入：指数走势、成交量、涨跌家数、主线板块、重要消息。

输出：
- 当日市场状态：强修复、弱修复、震荡、退潮、兑现、逼空
- 次日关键观察点：指数位置、量能变化、题材承接、核心股反馈
- 仓位建议区间：轻仓观察、正常参与、降低进攻性

### 2. 题材强弱 Skill

输入：板块涨幅、核心股表现、涨停梯队、消息催化、分歧程度。

输出：
- 题材阶段：启动、发酵、加速、一致、分歧、修复、退潮
- 核心标的识别：容量核心、情绪核心、趋势核心、补涨跟风
- 操作结论：继续看核心、只低吸、不追高、等待分歧、回避兑现

### 3. 个股上车 Skill

输入：个股位置、前高、量能、分时承接、板块地位、当日情绪。

输出：
- 上车类型：缩量过前高、低吸回踩、涨停炸板承接、连板一进二
- 触发条件：放量确认、缩量承接、分时不破关键位、板块同步加强
- 失败条件：放量滞涨、跌破承接位、跟风掉队、题材退潮

### 4. 卖点和风控 Skill

输入：持仓成本、浮盈浮亏、分时走势、量能变化、板块状态。

输出：
- 卖点类型：冲高兑现、破位减仓、放量异常、尾盘弱化、题材退潮
- 仓位动作：锁利润、降仓位、保留观察仓、全部离场
- 心理校准：怕踏空和怕回调不能同时解决，需要先选自己的风险偏好

### 5. 盘口/分时识别 Skill

输入：分时曲线、成交量、盘口挂单、拉升/回落节奏。

输出：
- 分时行为判断：吸筹、洗盘、出货、承接、诱多、弱修复
- 关键证据：量价配合、回落深度、拉升持续性、均线承接、尾盘态度
- 行动建议：观察、低吸、减仓、放弃

## 内容风格

- 结构上常用“今天盘面发生了什么 -> 为什么这么走 -> 明天怎么应对 -> 个股怎么处理”。
- 语言上强口语化，适合视频表达，也适合转成训练型 checklist。
- 标题常直接打中新手痛点，比如洗盘/出货、如何卖票、如何上车、低吸战法、分时卖点。
- 观点表达偏强，但底层其实是概率和情景推演：如果走 A，观察什么；如果走 B，怎么处理。

## 适合沉淀成知识库的核心概念

- 市场阶段：修复、退潮、兑现、逼空、轮动、普涨、分歧
- 题材结构：主线、支线、核心、跟风、补涨、容量、情绪标
- 个股结构：趋势、连板、炸板、缩量过前高、平台突破、回踩承接
- 分时语言：均线承接、放量拉升、缩量回踩、尾盘抢筹、尾盘兑现
- 风控动作：仓位控制、止盈、减仓、观察仓、失败条件

## 风险和局限

- 强依赖短线语境，对没有盯盘时间的人不友好。
- “主力行为”类判断可解释性强，但也容易出现事后归因，需要配合可量化条件。
- 题材和消息驱动容易受市场环境影响，不能把某一期视频里的结论机械迁移。
- 自动字幕存在识别误差，后续做知识抽取时需要保留原视频链接和时间轴便于回查。

## 下一步建议

1. 把 48 条字幕按上面的 5 个 Skill 模块切块，建立 `concepts / tactics / checklists / cases` 四层结构。
2. 每个视频抽取 3 类资产：核心观点、操作条件、失败条件。
3. 对教学类长视频优先做结构化，比如“主力抬轿”“10 倍股”“盘口详解”“低吸战法”“分时卖点”。
4. 对每日复盘类视频只保留市场判断框架和案例，不把时效性结论当长期知识。
5. 生成一个“短线交易助手”的提示词，让它回答时必须输出：市场阶段、题材阶段、核心标的、买点、卖点、失败条件、仓位。
